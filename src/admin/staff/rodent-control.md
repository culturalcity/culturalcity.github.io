# 立即行動清單

要動手時看這一節就夠。後面各節是原理與判準，需要時再查。

## 採購（約 1,500～3,000 元，修繕雜支）

| 品項 | 數量 | 單價（估） | 挑選重點 |
|---|---|---|---|
| 防拆式站體（市售名稱：捕鼠屋／鼠餌站） | 3 | 200–500 元 | 標示可用於室外・能上鎖或卡扣・**內部放得下捕鼠夾**（§3.2）|
| 快扣式捕鼠夾 | 6 | 50–150 元 | **不是捕鼠籠**，籠子放不進站體 |
| 6 公釐鑽頭 | 1 | 數十元 | 當量規用（§2.1）|
| 花生醬 | 1 罐 | 百元內 | 誘餌，**不用藥劑** |

金屬門底條等門縫量完知道規格再買。

## 時程

### 今天

- [ ] 漢他伏**原包裝密封**，收到管理中心上鎖或幼童無法取得處，標示「未使用・勿棄置戶外」（§4.2）
- [ ] 回報：一張存放照片

### 本週

- [ ] 採購上表四項
- [ ] **建築物開口普查**（§2.2）：用 6 公釐鑽頭量，塞得進去就記下並拍照
- [ ] **社區自身食物與水源查核**（§3.1）：環保室、餵貓餵鳥、積水漏水、落果堆肥，拍照
- [ ] 回報：兩份清單與照片交主委，由主委發包

### 下週

- [ ] 站體就位：放在已知鼠徑上、貼牆（沿花園牆基橫越 → 鐵門下緣，§3.2）
- [ ] 預餌：夾具不設定，只放站體與花生醬；**誘餌開始被吃才設定**（通常 3–5 天，以取食為準）
- [ ] 交代清潔或保全：每天巡場時**開站檢查一次**（鑰匙放管理中心）；預餌期看到誘餌被吃要通報；**已死亡**的當場消毒、雙層袋處理並通報；**未致死的不碰、關站、通報**（§3.2）

### 之後（常態）

| 頻率 | 誰 | 做什麼 |
|---|---|---|
| 每天 | 清潔／保全 | 開站檢查（鑰匙在管理中心）。**已死亡**：消毒、雙層袋、通報。**未致死**：不碰、關站、通報 |
| 每週 | 總幹事 | 巡檢、清理、重設、填監測表；調閱後門監視器（§3.3）|
| 每月 | 總幹事 | 於管委會議摘要回報趨勢 |

## 怎麼算成功

| 指標 | 目標 |
|---|---|
| 建築物開口封堵完成率 | 清單逐項完成 |
| **室內鼠蹤** | **零**（紅線）|
| 花園監測數字 | 維持低檔並逐週下降 |

**捕獲數不是指標。** 理由見第一節。

# 一、目標與四個決定

2026 年 9 月，後花園發現鼠蹤，**室內尚未被侵入**。天氣轉涼後鼠群會往室內移動，現在是防守，等住戶在梯廳看到就變成清剿。

## 目標：守住建築物，不是清除老鼠

外部食物源在哪還不確定，也無權處理鄰地；只要外面有食物，族群就會補回來。追求「零老鼠」沒有終點線。

| 區域 | 定位 | 做什麼 |
|---|---|---|
| **建築物外殼**（門、通風口、管線孔、上層開口）| **紅線・可控** | 封堵到 6 公釐（第二節）。錢和力氣集中在這裡 |
| **後花園** | 緩衝區兼預警區・不可封閉 | 降低吸引力＋監測（第三節）。**不投資周界封堵** |
| **後巷與鄰地** | 不可控 | 睦鄰溝通，不投入防治資源（§4.1）|

花園的監測本質上是建築外殼的早期預警：活動上升時，先回頭查外殼有沒有新破口，不是加強捕捉。

## 決定一：不用毒餌，改用捕鼠夾

社區有黑貓常態出沒（尤其夜間），而里辦公室配發的漢他伏是**第二代抗凝血劑**（§4.2）。防拆站體能降低貓直接吃到毒餌的機會，**但擋不住牠吃到中毒的老鼠**——中毒鼠有數日行動遲緩、警覺下降，更容易被貓捕食，這個風險靠容器設計消除不了。目標本來就不需要毒殺，不值得為多殺幾隻老鼠冒讓一隻貓死掉的風險。

捕鼠夾的代價是要勤巡視；好處是捕獲數直接可見、沒有中毒鼠屍散落。

**重新評估用藥的前提**：確認貓已長期不再出沒，且經主委同意。屆時須核對包裝的品名、有效成分、許可證字號，並依標示施用。

## 決定二：不在花園周界投錢，包括鐵門底縫

花園柵欄不落地，底下是約 60–70 公分的花圃牆；唯一的地面開口是巷側外圍鐵門的門底楔形縫，2026-09-11 監視器實拍鼠隻由此進出（§4.6）。乍看「補了這一個洞就好」，但：

- 60–70 公分擋不住鼠——溝鼠的垂直跳躍能力已接近此高度，屋頂鼠更是輕易攀爬，花圃的土壤與植栽就是踏腳處。
- 花園通行量不是我們的指標，減半也不直接貢獻「室內零鼠蹤」。
- 那道縫地面斜、門扇會擺動下沉、縫內積灰，**做不到穩定 6 公釐**；花錢買一個達不到的規格是最糟的支出。
- 補死地面開口會逼牠們改從別處翻牆，而那些地方沒有攝影機——等於花錢買到「看不見」。

鐵門若日後因其他原因施工，順便處理，技術重點見 §4.3。鐵門常被留著開是門禁問題，依門禁辦法處理，不包裝成防鼠措施。

## 決定三：食物源未確認，但也未排除

手上的證據只有「影片看來離後巷夯飽排骨飯很近」——鄰近性，不是因果。總幹事已前往溝通，對方回應「無從追究來處」，這個回應合理。本社區 83 號店面無餐飲業，不是餐飲來源；其垃圾與堆置仍在 §3.1 自身查核範圍內。

這對作法影響很小：封堵、降低花園吸引力、監測，三件事不論來源是誰都成立。唯一的影響是**不要期待「跟鄰居談好就沒事」**。對外處理見 §4.1。

## 決定四：捕捉是過渡措施

捕捉的目的是在封堵完成前壓低壓力，不是清空花園。封堵驗收完成、監測歸零後，撤夾具改放無毒監測塊、巡檢降為每月（§3.4）。

# 二、封堵建築物開口

## 2.1 判準：6 公釐

| 種類 | 可通過的孔隙 |
|---|---|
| 溝鼠成鼠 | 約 1.2 公分 |
| 小家鼠、幼鼠 | **約 6 公釐** |

不知道現場是哪一種，一律以 6 公釐為準；用溝鼠的數字等於放行所有小家鼠。

- 帶 **6 公釐鑽頭**或直尺實測，塞得進去就要處理。
- 不要用手指或原子筆比——原子筆桿約 7–9 公釐，會放過 6–8 公釐的縫。
- 門底縫同標準，超過即加裝金屬門底條。
- 建築物的門檻是平整面，裝門底條可貼合到 6 公釐，這是常規工程；管線孔與百葉也能封到零縫隙。**做得到的地方才值得花錢**，這是決定二的依據之一。

## 2.2 檢查位置（依序）

1. **建築物後門門底縫**——最優先
2. 其他出入口、機房門、防火門的門底縫與門框縫
3. 地下室通風百葉、機房開口——格柵破損或孔徑過大
4. 管線穿牆、穿樓的套管孔洞——最常漏封，尤其後加裝的線路
5. 排水明溝與溝蓋——蓋板間距、破損處
6. 一至三樓開窗、陽台、排氣口
7. 上層與頂樓的通風口、管道間開口——老鼠會爬，見 §2.3

列清單附照片與實測尺寸，報主委後由社區修繕廠商施作。完工用 6 公釐鑽頭驗收，拍照存檔。

## 2.3 切斷攀爬路徑

屋頂鼠可直接沿粗糙垂直牆面上爬，也沿電線、水管、冷氣管線、枝條藤蔓移動；溝鼠亦具攀爬能力。建築外殼是立體的，閱大安 15 層加頂樓空中花園，上層開口要納入。

| 橋樑 | 處理 |
|---|---|
| 貼牆或近牆的樹枝、爬藤 | 修剪至離外牆至少 1 公尺，交代綠石園藝納入例行 |
| 落水管、冷媒管、排氣管 | 必要時於管身加裝金屬防鼠擋板（套在管上的圓盤）|
| 外牆電纜、網路線 | 同上，或改管槽收納並封住端口 |
| 牆邊雜物、棧板、盆器 | 移除，它們是「第一階」|
| 各層通風口、排氣口 | 加金屬紗網罩，不用塑膠紗網 |
| 頂樓空中花園 | 比照花園：不供食、不積水、不留掩蔽；檢查通往室內的門窗 |

## 2.4 材料

| 可用 | 不可用 |
|---|---|
| **不鏽鋼**絲絨塞實＋外層水泥抹平 | 一般碳鋼絲絨（戶外數月即鏽蝕粉化）|
| 鍍鋅或不鏽鋼細目金屬網 | 矽利康、泡棉、保麗龍、木板、膠帶 |
| 金屬門底條 | 橡膠條、毛刷條（會被啃穿）|

發泡填縫劑只能當固定，不可裸露當防鼠面層——老鼠照樣啃穿。

# 三、花園：降低吸引力＋監測

## 3.1 先查我們自己這端

「一樓周邊應該沒有食物源」是推測，要實查拍照：

1. 環保室與垃圾集中點——桶蓋密合、垃圾落地、清運頻率、地面殘渣油污
2. 有無住戶或鄰居餵流浪貓、野鳥——問保全與清潔，他們最清楚
3. 積水與長期潮濕處——盆底、低窪、滴漏水龍頭。老鼠每天要喝水
4. 植栽落果、堆肥、鬆軟土堆
5. 騎樓與後巷我方側的堆置物

環境整理併入綠石園藝與清潔例行：清除堆積物、閒置盆器、落葉堆；沿牆留 30–50 公分淨空帶；草皮灌木修低；花圃植栽不垂到牆外側、藤蔓不攀牆。

## 3.2 站體與捕鼠夾

**選購**四件事：標示可用於室外；可鎖或卡扣；內部有固定裝置（餌棒、卡榫或固定孔）；**內部放得下捕鼠夾**——先決定夾具型號量好長寬，再對照站體內部尺寸或問賣家，市售不少窄版是給餌塊用的。深灰或黑色，兩三個即可。4 吋 PVC T 型管自製便宜但無防拆，只用於幼童與寵物不會接近之處。

**設置**：每站一至二個快扣式捕鼠夾，依原廠方向安裝，**踏板（觸發板）朝向站體入口**；誘餌用花生醬（黏稠、叼不走），量少即可；戴手套並小心彈力。站體用底部固定孔以膨脹螺絲或綁固於固定物，不能鑽孔處以重物壓住；上鎖或卡扣，鑰匙放管理中心。**第一個站體放在已知鼠徑**——沿花園牆基橫越至鐵門下緣——貼牆、灌木或設備後方，避開幼童動線。

**預餌**：一開始夾具不設定，只放誘餌讓牠們習慣進出；**看到誘餌被吃才設定**，通常要三到五天，但以取食為準、不看日期。老鼠對新物體會迴避一兩週，一開始就設定通常是白等，還會被誤判成沒有老鼠。

**巡視**：站體上鎖後從外面看不出夾具狀態，**每天要開站檢查一次**——清潔或保全巡場時開站、看、關站。預餌期看到誘餌被吃就通報總幹事（那是設定夾具的時機）。總幹事每週正式巡檢、清理、補誘餌、填監測表。捕獲物久置會有異味蒼蠅，該站也失效。

**捕獲處理**（戴手套與口罩）：先對鼠屍與夾具噴 1：9 漂白水、靜置 5 分鐘，再雙層袋密封丟一般垃圾；接觸處消毒；夾具以漂白水沖洗、晾乾後再重設；脫手套後洗手；通報總幹事。

**未致死的鼠，第一線不處置**：不徒手接近（鼠咬有感染風險），關站、通報總幹事，由總幹事交廠商處置。被咬立即以肥皂水沖洗並就醫。

**標示**（貼於站體）：

> 病媒防治設備・請勿移動或開啟
> 內含機械式捕鼠夾（不含毒餌、無藥劑）
> 開啟有夾傷風險，如需處理請洽管理中心 分機 ○○○

明寫「不含毒餌」讓住戶不必擔心寵物與幼童。若未來改用毒餌，標示須整張換掉，載明品名、成分、世代與解毒劑——寫錯的解毒劑會誤導急診，比不寫更糟。

**戶外不用黏鼠板**：會黏到麻雀、蜥蜴、幼貓，也會變成社區事件。

## 3.3 監測

**先用既有監視器。** 後門花園朝鐵門的鏡頭已涵蓋主要鼠徑，24 小時不間斷。保全交接時順帶留意，總幹事每週調閱一次，重點看夜間與鐵門附近。拍到就從主機匯出原始檔（不熟操作可洽監視系統廠商教一次），不要手機翻拍螢幕，翻拍損失大半細節。看的是趨勢：每週幾次、什麼時段、走哪條路。

**目視監測點** 3–5 個（花園牆角、溝蓋旁、環保室旁、後巷側），不放餌，只看跡象。站體兩三個就夠，目視點可以多。

| 日期 | 監測點 | 新鮮鼠糞 | 啃咬痕 | 洞口活動 | 夾具觸發／捕獲數 | 鼠屍 | 備註 |
|---|---|---|---|---|---|---|---|
|  | 1. |  |  |  |  |  |  |
|  | 2. |  |  |  |  |  |  |
|  | 3. |  |  |  |  |  |  |

**新鮮鼠糞**：深黑有光澤＝新鮮；灰白褪色＝陳舊。不要用手按壓判斷。更可靠的作法是第一次巡檢把鼠糞全清掉，之後看到的一定是新的。

> ⚠️ **清鼠糞的安全作法**：鼠類排泄物乾燥後形成含病原粉塵（漢他病毒即為其一）。戴手套與口罩；先用漂白水以 1：9 稀釋噴濕、靜置 5 分鐘；濕紙巾或夾子撿拾，雙層袋密封；**絕對不要乾掃或用吸塵器**；處理完洗手。

**洞口活動**用薄土覆蓋法：少量鬆土輕覆洞口不填實，下週看。被推開＝使用中，站體可移近；原封不動只能暫列疑似無活動——老鼠會間歇使用，雨天低溫也會幾天不出門——重新覆土，**連續兩次原封不動**才判廢棄封填。

**三條判讀原則**：

1. 不只看捕獲數。捕獲下降也可能是新警戒期、位置放錯、站體被擋、誘餌乾掉或被螞蟻佔、鄰地出現更好吃的食物。要與鼠糞、啃咬痕、洞口活動一起看，四項同步下降才有意義。
2. 捕獲數高代表族群還在，不是措施有效。要看到逐週下降。
3. 完全沒動靜時先查新警戒期、誘餌狀態、位置，不要直接判定沒有老鼠——這是最常見的誤判。

**環境中的鼠屍**：每週巡檢順帶搜尋花園、灌木下、設備後方、牆角；戴手套與口罩，先噴 1：9 漂白水靜置 5 分鐘，再雙層袋密封處理。來源不明的鼠屍要特別留意——若鄰地投藥，中毒鼠屍就是黑貓二次中毒的來源，即使藥不是我們下的。

紀錄放 Google Drive 社區檔案，每月管委會議摘要回報。

## 3.4 何時轉為純監測

同時滿足：①第二節開口清單已封堵並驗收；②連續 3 週各監測點皆零、無捕獲。

作法：站體保留；撤下夾具清潔收存；改放**無毒監測塊**（里辦公室不配發，自行向五金行或網購採購，列修繕雜支）；巡檢降為每月。

**恢復捕捉的時機**：監測塊出現齒痕，或**室內發現任何鼠蹤**——後者是紅線，同時回頭查外殼破口。

# 四、對外與備查

## 4.1 後巷店家

| 不再做的 | 要繼續做的 |
|---|---|
| 不再就此事向對方詢問或施壓；不對外指名；不向主管機關陳報 | 保留為候選來源之一；監測點若長期某一側明顯較高、鼠徑方向一致指向某處，那才是證據；對方若委請廠商施作，記錄時程 |

對外一律講「來源不明、周邊共同防範」。後巷是每天共用的空間，關係要留。日後若要走主管機關管道，須先有指向性證據，受理單位請先電洽大安區清潔隊確認並回報主委，在此之前不向店家提及。

鄰地若開始防治，鼠隻可能往我方移動，那段期間監測數字上升是合理的，不要誤判為我方措施失效；鄰地若用毒餌，我方會出現中毒鼠屍，加強 §3.3 的搜尋。

## 4.2 漢他伏：規格與保存

古莊里辦公室配發，50 公克餌劑，有效成分**伏滅鼠（Flocoumafen）0.005% w/w**，第二代抗凝血劑：單次取食即達致死量、肝臟殘留期長、二次中毒風險明顯高於第一代；取食後約 3–7 天死亡；解毒劑維生素 K1，療程長達數週、須獸醫或醫師評估；人或寵物誤食立即送醫並攜帶包裝。

保存：原包裝密封，管理中心上鎖或幼童無法取得處，標示品名與「未使用・勿棄置於戶外」；可洽里辦公室詢問退回。**已受潮的餌料屬環境用藥廢棄物，不要自行推定丟法**——先看包裝處置說明，未載明則電洽大安區清潔隊或環保局，確認前雙層袋密封暫存。未直接盛裝藥劑的外層紙箱清潔後依一般廢棄物處理。

## 4.3 鐵門楔形縫：若日後施工的技術紀錄

地面傾斜、門扇下緣平直，夾出一端寬一端窄的楔形縫，且整條都超過 6 公釐（老鼠在偏窄段即可通過）。若因維修、更換、美觀等原因施工：

- 一般門底條無效——假設地面平行，裝上只貼合窄端。
- 橡膠條、毛刷條會被啃穿。
- 不要用水泥墊平地面——斜度多半為排水，填平會積水，積水又是老鼠要的水源。
- 建議依實測斜度裁切鍍鋅或不鏽鋼板，加焊或鎖固於門扇下緣，板隨門移動；深度沿門寬漸變，不可用等寬料。
- 驗收沿整條每約 30 公分量一次，每一點小於 6 公釐；門扇開闔數次後再量。
- 後門是逃生動線，任何措施不得妨礙開闔與通行，不可上鎖固定死。

## 4.4 與潤泰維護的分工

每月保養排程中的消毒廠商就是潤泰維護（物業管理廠商本身）。總幹事只需整理現場事實——鼠蹤位置、監測紀錄、封堵清單、照片；現行合約消毒範圍是否涵蓋鼠害防治、是否加做，由主委直接與潤泰洽談。若改由外部廠商施作，須為合法登記的病媒防治業並由專業技術人員督導。

## 4.5 判斷是哪一種老鼠

| 跡象 | 偏向 | 巡查重點 |
|---|---|---|
| 土壤鼠洞、地面鼠徑、沿牆基活動 | 溝鼠（地棲挖洞）| 地面孔隙、牆基、排水溝 |
| 管線、樹枝、高處的鼠糞或擦痕 | 屋頂鼠（善攀爬）| 上層開口、管線、藤蔓 |

判斷不出就兩邊都做。不論哪一種，建築物開口一律 6 公釐。
