# 為什麼要做這個

閱大安是**列冊的公共防空避難處所**（門牌處設有內政部「防空避難標誌牌」）。臺北市每年舉行「城鎮韌性（全民防空）演習」，依《民防法》第 21 條、《防空演習實施辦法》第 7、12 條，大廈管理人在演習時**有配合開放地下室避難設施、供民眾就近避難的義務**；未配合者，得依《民防法》第 25 條處 **3 萬～15 萬元**罰鍰。

難處在於：**既要開放給公眾避難，又要守住社區門禁。** 做法是「分層、戒護、復歸」，兩者可以兼顧。

> 開放地下室是管委會內部執行的事，**不對住戶公告**；給住戶的公告只宣導「聽到警報怎麼避難」。

# 每年收到演習訊息時（總幹事）

1. **查當年的日期與管制時段**：以臺北市政府官方網頁公告為準。新聞稿與網路整理文章曾經寫錯時間，不要照抄。
2. **排定當天在場的保全**，把本頁給他看。
3. 若警察局或民防管制中心另有**個別通知或更細的訓令**，一律以通知為準。
4. 住戶的避難宣導公告由主委發布，內容不提開放地下室。

警報音全國統一：

| 項目 | 內容 |
|---|---|
| 空襲警報 | 1 長音＋2 短音，連續 3 次 |
| 解除警報 | 1 長音，鳴放 90 秒 |
| 管制時間 | 通常約 30 分鐘（警報傳遞、疏散避難、交通管制） |

# 門禁戒護原則：把大樓想成「兩層殼」

1. **外殼＝地下室停車場**（演習要開放的避難區）→ 依訓令開啟車道鐵捲門。
2. **內殼＝電梯與住宅樓層門禁** → **全程維持上鎖**。

開放的是外殼。進來避難的人留在停車場層避難即可，**上不了樓、進不了住家**。

# 當天流程

| 時間 | 動作 |
|---|---|
| **前一天** | 確認：① 地下室避難區淨空、動線與標示清楚 ② 車道鐵捲門手動／自動切換正常、逃生小門正常 ③ 手電筒、哨子就位 |
| **管制開始前 15 分鐘** | 保全到地下室車道開口待命；再次確認**電梯與住宅樓層門禁維持上鎖** |
| **空襲警報響起** | 依現場民防人員訓令**開啟車道鐵捲門**；引導避難民眾到停車場**指定避難區**，明確**擋住往電梯、住宅的動線** |
| **演習中** | 維持秩序、留意進入人數；不讓任何人上樓；聽從民防人員指示 |
| **解除警報後** | 引導民眾離場 → 清點 → **鐵捲門復歸** → 確認門禁全數復原 |
| **事後** | 回報主任，由主任回報主委：有沒有民眾進入、大約幾人、有無異常 |

# 注意事項

- **鐵捲門復歸要小心**：降門前務必確認**逃生小門先關、門面完整**再落下。2026 年 5、6 月防火鐵捲門曾兩度在小門沒關時降下，門片脫軌外凸（Notion 議題追蹤 ID 168）。
- 民防相關疑義，洽臺北市政府警察局民防管制中心。
