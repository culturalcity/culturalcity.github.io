地震停止後，依序執行：

# 1. 人員安全

- 看監視器畫面，確認各公共區域有沒有人受傷或受困。
- 確認電梯是否停止運作、有沒有住戶受困；有就立即聯繫三菱救援。三菱電梯會自動停靠到某一層並開門，不一定是一樓，每部都要確認。

# 2. 設施巡檢（由上往下）

- **頂樓**：水塔、水箱有無破損或位移，管線有無斷裂漏水。
- **各樓層梯廳與走廊**：天花板、消防灑水頭有無鬆脫或漏水；**5 樓至 7 樓牆面磁磚**有無「膨拱」（空心）或剝落（403 大地震後的災損經驗）。

# 3. 地下室

- 停車場 Epoxy 地面有沒有新的裂縫。
- 發電機房、各機電設備、管線有沒有損壞或漏水。
- 連續壁有沒有滲水或裂痕。

# 4. 瓦斯

- 巡查有沒有瓦斯味；有就立即關閉總閥，通知瓦斯公司。

# 5. 回報與公告

- 初步巡檢結果立即回報主任與主委。
- 由總幹事在「社區公告 LINE 群組」發布初步安全通報。
- 電梯停用時，在各樓層電梯口張貼停用公告。

# 6. 記錄災損

- 所有災損拍照、錄影，上傳 Google Photos。
- 非緊急的災損（例如地下室 Epoxy 裂縫）可經管委會決議後列入議題追蹤。
