規定的正本是[《裝潢修繕施工管理辦法》](/regulations/regulations-裝潢修繕施工管理辦法.html)，金額、罰則以辦法為準。本頁整理現場要怎麼做：施工期間天天在現場的是保全，發現問題的機會最多。

# 保全：每天在櫃台

- **施工人員**：每天施工前到櫃台登記、換識別證，在社區內要配掛；沒換證、沒配掛的不得進入（第五條第 2 款）。
- **載貨車輛**：先到櫃台登記換證，才能進地下停車場卸貨；卸完立即駛離（第 4 款）。施工人員與材料一律走地下室與貨梯（第 3 款）。
- **施工時間**（第 11、21 款）：

| 項目 | 時間 |
|---|---|
| 一般施工 | 週一至週五 08:00–12:00、13:30–17:30；18:00 前所有人離開 |
| 拆牆、敲打、電鋸、氣釘等噪音工程 | 09:00–12:00、13:30–16:30，且須提前三天申請 |
| 週六 | 須提前三天申請靜音施工，經管理中心核准才可以 |
| 週日、國定假日 | 一律不准進場 |
| 颱風停班停課期間 | 停止施工 |

# 保全：巡邏時看什麼

- 電梯、梯廳、走道的保護材有沒有破損或移位；該戶門口有沒有透明防塵布簾。
- 梯間防火門要關著；施工戶的大門要關但不得上鎖（第 7 款）。
- **排煙窗不得打開**，會觸發火警（第 14 款）。
- 建材、砂石、垃圾不得堆在公共區域，也不得丟進垃圾間；施工人員不得使用公設洗手間（第 17、20、26 款）。
- 收工前 30 分鐘巡一次電梯與動線的清潔。

**發現違規**：拍照、記下時間與戶別，回報主任；開罰與從保證金扣款由總幹事依辦法處理，保全不必在現場爭執。

**施工弄壞公共管線**（漏水、斷電、消防誤動作）：請施工方先停工、立即回報主任，並依[漏水](/security/sop/water-leak/)或[消防警報值勤流程](/security/sop/fire-alarm/)處理；修復由裝修戶與承包商負責（第 22 款）。

# 總幹事：申請到退場

1. **申請審核**：依《建築物室內裝修管理辦法》判斷要不要向建管處申請許可。必須申請的情況：固著於構造體的天花板、內部牆面（不含壁紙壁布）、高度超過 1.2 公尺的固定隔屏（含系統櫃）、分間牆變更。查核保證金與預繳清潔費的匯款證明、申請單、切結書、施工圖、許可文件。開工日七日前提出申請。
2. **保護工程會勘**：廠商施作保護「之前」，先錄影存證公共區域現況，釐清責任。保護材標準：地板與壁面三層（防水布＋PP 板＋木板）；電梯雙層（PP 板＋木板），門框也要保護；施工戶門口透明防塵布簾。
3. **完工**：協同測試前後陽台排水是否暢通。
4. **拆除會勘**：拆除保護材時再會勘一次，確認公共區域無損後才退還保證金。
