停車場出入口所在的羅斯福路二段 81 巷是單行道、只容一線車道，任何臨停都會讓車輛無法進出。

1. **現場查勘**：判斷性質（救護、故障、違停、卸貨）與預估時間。
2. **通知住戶**（由總幹事）：在「住戶討論 LINE 群組」發布事由、影響範圍、預估時間、建議（例如暫緩返家）。
3. **現場引導**：時間長的話，保全到巷口引導，避免車輛誤入。違停又聯繫不到車主時，通報警方。
4. **解除通報**：恢復暢通後再發訊息告知住戶。
5. 記入工作日誌。
