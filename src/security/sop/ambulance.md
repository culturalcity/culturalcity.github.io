# 救護車到場

1. 撥 119，說明狀況與樓層。
2. 調低周遭廣播、對講機音量，避免驚動其他住戶。
3. 協助救護人員刷電梯到指定樓層，其餘交給救護隊。
4. 一樓用輪椅接駁，轉換擔架車運送。

# 事後回報

- **工作日誌**：記時間、救護車到場與離開，以及有沒有牽涉公共設施（例如在公設滑倒、電梯或門禁擋住救護人員）。**不寫是哪一戶、不寫病況**。
- **是哪一戶**：當天私訊告知主任，由主任私訊告知主委，讓社區有機會關心住戶。**不在工作群組或其他公開場合提起**。
- **住戶要求保密時**：照樣私訊告知主任，並說明「住戶希望保密」；主委知情，但不會主動探問。
- 病況一律不記、不傳——醫療資料是個資法保護的特種個資。
