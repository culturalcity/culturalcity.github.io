# 前言

歡迎您到閱大安值勤。這份 Wiki 整理的是在這個社區櫃台做事的實際方法：一天怎麼過、遇到什麼情況怎麼判斷、出事時先找誰。內容主要來自本社區資深日班保全的訪談，再對照社區現行規定整理而成；夜班的作業細節尚未收錄。

如果只能記住三件事，就是這三件：

1. **認得住戶**：臉和戶號對得上，是所有服務的基礎。
2. **熟悉系統**：智生活（包裹、郵件登記）與監視器系統。智生活多數保全都會；每個社區的監視器系統都不一樣，才是新人真正要花時間熟悉的。不熟就請主任（總幹事）幫忙，主任也不會就直接問廠商。
3. **不確定就回報**：遇到手冊沒寫的情況，先回報主任；週末主任不在時，向管理委員通報。

社區規約與各項辦法以網站「[社區規約](/regulations/)」為準，本 Wiki 只寫櫃台實務。出狀況時的處理步驟，一律寫在「[作業程序總覽](/security/sop/)」（保全、總幹事共用），本 Wiki 只放連結。

# 一、標準的一天（日班 07:00–19:00）

## 1. 到班交接（07:00）

與夜班**對點**，逐項確認後記在**交接本**：

- 磁卡／磁扣、冷氣遙控器、印章
- 住戶寄放的現金與待付款項（重大事項，一定要對點）
- 公設鑰匙與設備鑰匙：目視確認，不記入交接本

接著登入**您本人的**智生活帳號（不要用別人的帳號，見第四章 §2），並巡一圈燈，關掉夜班漏關的燈。

## 2. 一天的節奏

| 時段 | 重點 |
|---|---|
| 07:00–09:00 | 住戶上班出門尖峰，留意住戶動態 |
| 09:00–11:00 | 郵差、物流頻繁進出，包裹收發高峰 |
| 12:00–13:00 | 彈性休息一小時，人在櫃台附近 |
| 下午 | 主任交辦事項；跟進住戶的公設、包裹、信件需求 |
| 17:00–20:00 | 外送晚餐與住戶返家尖峰 |
| 18:00 | 開啟社區該開的燈 |
| 19:00 | 與夜班交接、下班 |

## 3. 與夜班交接（19:00）

對點當日包裹、磁扣、鑰匙、信件、寄放金額，並交辦住戶委託的事（例如「晚上八點幫我叫一台計程車」）。

**口頭與文字並行**：重要的跨班指令（例如夜間燈光設定）請同步寫進交接本與工作群組，避免口頭轉達時遺漏。

# 二、認人與住戶服務

## 1. 認人

- **先認識管理委員**：是誰、住幾樓。週末主任不在時，突發狀況除了回報公司，也要通報委員。委員名單放在櫃台交接夾。
- **認得住戶可以解決大約一半的日常問題**，尤其是訪客確認和包裹歸戶。
- **記衣服比記臉容易**：櫃台多半只看到側臉，新人又緊張；每個人的穿著風格很固定，飯店與百貨業也是這樣記人。

## 2. 開門與協助

- **開門默契**：住戶不一定開口，用眼神判讀。出門的人，直接幫開門；進門的人，要判斷是不是住戶；住戶大包小包回來，主動幫開門。
- **不代提重物**：這是社區已經確立的原則，住戶也接受了。物品多時，有空可以幫忙放上推車，或送進電梯，以住戶方便為準。
- **住戶有磁扣卻請您代刷電梯**：用服務的語氣軟性提醒，例如「需要幫您新增一張卡片嗎？」，不正面起衝突。
- **單人值班時事情撞在一起**：現場住戶優先，外送稍候。

## 3. 住戶家裡的事

- **住戶家內漏水、水電**：社區沒有固定配合的水電行，可以協助查附近營業中的水電行給住戶參考；假日則請住戶聯繫自己的設計師或原施工師傅。**保全不進入住戶家中**。
- **建材類損壞**（磁磚裂、玻璃破、門鎖故障）：住戶多半會先找建商；相關廠商名單已公告在社區的公共平台，也可以參考網站的[廠商聯絡簿](/directory/)。

# 三、門禁、訪客與停車

## 1. 訪客

- **訪客可信度的第一依據，是住戶事先知會櫃台**。
- 現場訪客掃櫃台的 QR code 登記，保全在[訪客出入紀錄](/security/visitors/)確認到場、離場並簽名。需要借磁扣時，**換證要落實**：登記進場時間、換證時間、離場時間，離場時確認證件歸還。換證是最容易鬆掉的環節。
- **訪客開車**：社區沒有公共訪客車位（建築設計本來就沒有）。住戶如果同意把自己的車位暫借訪客，先確認是哪個車位、目前沒有在用；其餘訪客來車，請對方自行找車位，通常在師大周邊。住戶搬家或搬運大型物品時，可以暫停 B1 環保室前，完成後就離開。一樓無障礙車位不開放訪客或一般住戶臨停（社區配合廠商臨停作業除外）。
- **廠商問路**（可以照著唸）：「我們在羅斯福路二段，往前看到星巴克右轉，看到和平東路 104 巷右轉，一路往前，過個小彎，就會看到我們的停車場了。」

## 2. 磁扣

- 交屋時每戶 5 顆。社區的基本款磁扣上沒有社區識別，掉了別人也看不出是哪一棟，比較安全。住戶要增加，可以向管理中心自費購買，或拿自己的悠遊卡請管理中心設定（[《門禁管理辦法》](/regulations/regulations-門禁管理辦法.html)第八條）。遺失時立即通知管理中心註銷。
- **設定由總幹事負責**：門禁卡與 eTag 的設定由總幹事統一維護，保全協助收件與登記（收條碼、準備資料），再交給主任設定。

## 3. 房仲與外來人員

房仲三鐵律：

1. 要租車位給外車的，一律拒絕。
2. 先確認來意，常常是來打探有沒有房子要賣或出租。
3. 不代為聯繫住戶，請對方自己打電話或與住戶約好。

背後的原則：**櫃台是住戶隱私的防火牆，不是仲介的情報站或總機**。保全可以「確認已經存在的約定」，不幫忙「創造新的接觸」。遇到手冊沒寫的新情況（代銷、調查、陌生拜訪），照這個原則判斷。

**來抄水電表**：公設鑰匙統一由櫃台保管，借出時紙本登記（誰、什麼時間）；這樣已經足夠，不必另外換證。無法陪同時口頭告知水電表位置，並留意對方只在要去的樓層活動，有異常回報主任。

# 四、包裹與智生活

## 1. 包裹

- 依主任交接的填寫樣版操作。部分住戶的姓名沒有照規範輸入中文全名，系統跳不出戶別時要手動輸入。
- **冷凍宅配**：住戶通常很快就來領，冷凍冷藏空間大致夠用；空間允許時能冷凍就冷凍、能冷藏就冷藏。冷凍庫很深又緊鄰小冰箱與牆面，大型保麗龍箱（整箱海鮮）放不進去時，請住戶儘快下樓領取。
- **貨到付款**：物業是中間傳遞者。物流到場要收款時，通知住戶下樓自己對接；住戶出國期間預先寄放款項屬於不得已的例外，寄放的現金交接時一定要對點。

## 2. 用您本人的帳號登記

包裹一律用**當班人員本人的**智生活帳號登記。每筆紀錄都帶操作者姓名，包裹有疑義時（遺漏、找不到、歸屬爭議）可以直接查到是哪一班經手，好釐清，也不會冤枉人。

## 3. 什麼時候找智生活後台

新增戶別、拆分戶別、管理費問題。這些都轉給主任處理，保全不必自己聯絡。

# 五、巡邏、燈光與垃圾

## 1. 巡邏

- 檢查怪聲音、燈具光衰、漏水。發現異常時，記下位置與現象，回報主任安排修繕。
- **間歇性的漏水看痕跡**：頂樓交換馬達曾在夜間間歇噴水兩三天，巡邏時都沒看到。不能只看當下有沒有滴水，要看地面的水痕和鏽跡。
- 有空時自行更換燈泡是個人的熱心，不是義務；以不影響櫃台勤務、確保自身安全為前提。

## 2. 燈光

- **深夜模式只關頂樓照明和大廳燈**。地下室（含車道、車位）已全面改成感應燈，**一律不關**——深夜返家的住戶會一片漆黑。
- 18:00 開啟社區該開的燈；早上到班時巡一圈，關掉漏關的燈。

## 3. 垃圾清運

- 清運業者要求垃圾打包好、直接上車才收，所以要打包。
- 環保室冷藏庫內常備 3 個大型橘色垃圾桶，桶內先鋪大垃圾袋，打包就是整袋從桶中拉起紮好。第 4 個桶平時放在 B4，過年等垃圾量大時才拿出來。桶身大約每月清洗一次，由清潔人員安排。
- 清潔人員休假的前一天，會先把垃圾盡量打包好放在冷藏庫角落、空桶鋪好新袋。連休兩天時會安排帶班人員。保全是否協助打包，依主任的安排。

# 七、職責分界

保全的核心工作是：認識住戶、收發包裹信件、門禁管控、影印、緊急事件通報。門禁設定、入住手續這類設定類的事由總幹事負責；保全碰到時做前置準備，交給主任處理。
